## 3.1 反向对照（2026-09-16 补）

把 `EditorPanel.tsx` 改回调用上游的 `openFilePreviewToSide` 并重新构建，跑同一条用例，**在面板数那一行失败**：

```
await expect(paneStrips(page)).toHaveCount(stripsBefore)
```

即分屏确实出现了、面板数从 1 变成 2。随后还原并复验通过。没有这一步，"通过"只说明用例没报错，不说明它在检测分屏。

失败截图 `evidence/00-before-fix-split-pane.png` 捕获的是分屏右侧那一栏的内容——`RENDERED HTML` 标题清晰可见。这顺带补上了 §3.2 里我声明过的缺口：**HTML 预览确实渲染出了像素**，只是修复前它被渲染在一个新开的分屏里。
