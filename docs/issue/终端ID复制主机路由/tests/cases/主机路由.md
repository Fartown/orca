# 主机路由测试用例

| 用例 | 需求 | 断言 |
| --- | --- | --- |
| 本地 | REQ-901、REQ-903 | 当前聚焦其他主机时仍使用本机 RPC，客户端写入 ID |
| 直接 SSH | REQ-901、REQ-903 | 已连接 SSH 经本机 runtime 查询；失联不查询 |
| 配对主机 | REQ-901、REQ-903 | 精确选择所属环境，git/folder/SSH 代理均支持 |
| 失败隔离 | REQ-902 | 归属不明、失联、RPC 错误不回退本机，不写剪贴板 |
| 剪贴板错误 | REQ-902、REQ-903 | 写入异常透传原菜单失败提示 |
| folder 归属缺失／歧义 | REQ-902 | folder 或项目组归属不能确定时拒绝；本机和配对 RPC、剪贴板均无调用 |
| folder 恢复与显式选择 | REQ-901、REQ-903 | 目录尚未加载但有已保存的配对主机时仍正确查询；同 ID folder 按显式选择的主机区分 |
| 本地旧格式 folder / floating | REQ-901、REQ-903 | 聚焦其他配对环境不改变已有本地终端的查询位置 |
| SSH folder | REQ-901、REQ-903 | 使用 controlling runtime，保留 SSH 连接检查 |
