# 远程大文件编辑器读取功能测试

这是可重复执行的测试规格；实际结果另记入 `../runs/`。需求来源为 [远程大文件编辑器读取](../../requirements/远程大文件编辑器读取.md)。

## 1. 功能清单

| 功能 ID | 关联需求 | 功能点 | 是否测试 | 预期表现 | Test Case |
| --- | --- | --- | --- | --- | --- |
| F-01 | REQ-701 | truncated 后分块补全 | 是 | 编辑器拿到完整内容 | TC-701、TC-705 |
| F-02 | REQ-702 | 跨分块多字节字符 | 是 | 与原文逐字符相等 | TC-702 |
| F-03 | REQ-703 | 对端过旧 | 是 | 报错含补救办法，不返回内容 | TC-706 |
| F-04 | REQ-704 | 上限与停滞保护 | 是 | 超限即停；无进展即停 | TC-703、TC-704 |
| F-05 | REQ-701 | 边界输入 | 是 | 空文件返回空串 | TC-707 |

## 2. 用例

单元用例的实现位置：`src/renderer/src/runtime-large-file/assemble-runtime-file-chunks.test.ts`（拼装器）、`src/renderer/src/runtime/runtime-file-client.test.ts`（读取链路接缝）。

### TC-701 分块按序拼回原文

- 关联需求：REQ-701；优先级：P0；类型：单元；模块：拼装器。
- 前置条件：模拟主机按 64 字节一块提供 500 行文本。
- 步骤：调用 `assembleRuntimeFileFromChunks`。
- 预期：返回值与原文严格相等。

### TC-702 多字节字符跨分块不被破坏

- 关联需求：REQ-702；优先级：P0；类型：单元；模块：拼装器。
- 前置条件：内容为 `中文中文中文`（每字 3 字节），分块大小 4 字节，必然从字中间切断。
- 步骤：调用 `assembleRuntimeFileFromChunks`。
- 预期：返回值与原文相等；读取次数大于 1（确认确实分了块）。

### TC-703 超过上限立即停止

- 关联需求：REQ-704；优先级：P0；类型：单元；模块：拼装器。
- 前置条件：文件 4096 字节，分块 512 字节，`maxBytes` 传 1024。
- 步骤：调用 `assembleRuntimeFileFromChunks`。
- 预期：抛出 `RuntimeFileTooLargeError`；读取次数少于 8（没有读完全文才判断）。

### TC-704 主机无进展时停止而不空转

- 关联需求：REQ-704；优先级：P0；类型：单元；模块：拼装器。
- 前置条件：模拟主机恒返回 `{ bytesRead: 0, eof: false }`。
- 步骤：调用 `assembleRuntimeFileFromChunks`。
- 预期：抛出 `Remote read stalled before reaching the end of the file`；只请求了一次。

### TC-705 读取链路在 truncated 时走分块并返回全文

- 关联需求：REQ-701；优先级：P0；类型：单元；模块：读取链路接缝。
- 前置条件：`files.read` 返回 `truncated: true`；`files.readChunk` 提供完整内容。
- 步骤：调用 `readRuntimeFileContent`。
- 预期：resolve 为 `{ content: <全文>, isBinary: false }`。

### TC-706 主机没有 files.readChunk 时提示补救办法

- 关联需求：REQ-703；优先级：P0；类型：单元；模块：读取链路接缝。
- 前置条件：`files.read` 返回 `truncated: true`；`files.readChunk` 以 `method_not_found` 失败。
- 步骤：调用 `readRuntimeFileContent`。
- 预期：reject，文案包含 `Update the Orca server to open files this size.`；不返回截断内容。

### TC-707 空文件

- 关联需求：REQ-701；优先级：P1；类型：单元；模块：拼装器。
- 前置条件：内容为空串。
- 步骤：调用 `assembleRuntimeFileFromChunks`。
- 预期：返回空串，不抛错。

### TC-708 真机：配对 runtime 上打开超过 512 KiB 的文件

- 关联需求：REQ-701；优先级：P0；类型：端到端；模块：编辑器。
- 前置条件：一台配对 runtime 主机；其 worktree 内有一个 600 KB 以上的文本文件。
- 步骤：从客户端在编辑器里打开该文件。
- 预期：文件正常显示全文，不出现「too large to open in the editor」。
- 备注：本轮**未执行**，缺少配对 runtime 真机环境；见测试记录 §4。
