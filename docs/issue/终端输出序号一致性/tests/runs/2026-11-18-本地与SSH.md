## SSH 场景和文件归属

客户端在本机，独立 HOME/profile、Electron 和 CDP 都属于客户端。本机 SSH 转发口 `127.0.0.1:<动态端口>` 映射到 Mini 的 loopback server 端口；这是现行 managed-server 路径的 SSH 隧道 + paired runtime，不是对旧 relay 的单独真机测试。

Mini 上 `/tmp/orca-sequence-host-*` 下的独立 Node、OrCAD、daemon、folder workspace、stdin 文件和故障控制文件全部属于 fixture。服务只绑定 Mini 的 127.0.0.1。主机 HOME、USERPROFILE、ORCA_USER_DATA、ORCA_E2E_HOME_DIR/USER_DATA_DIR 及 NODE_OPTIONS 都指向 fixture，用户原 App、daemon 和业务会话没有重启。

宿主与 daemon 的 socket 在 fixture 内真实关闭 1.2 秒。断流期间程序输出约 7.5 万字符后停止，因此等待不会让旧流自行追上。恢复后利用已有 E2E gate 真正丢掉一帧，并由下一帧的缺口让真实客户端自动请求快照。等待既有 5 秒输入隔离期结束后，走 xterm 输入管线发短串；未绕过保护或直接写客户端恢复状态。
