# 切换与绑定

- TC-1801（REQ-1801）：支持的终端右键显示聊天入口，点击仅调用同标签切换一次；聊天视图可返回终端，原 handle 和 PID 保持。
- TC-1802（REQ-1801）：普通 shell、无能力或缺少回调时不显示切换；原有历史会话操作菜单仍在正确分组。
- TC-1803（REQ-1802）：本地和真实 SSH 执行端分别运行隔离 App；已有 transcript 在两种展示间切换，终端进程保留。不新增或替换 provider 会话。
- TC-1804（REQ-1803）：核对用户旧标签的 provider session ID、执行主机 transcript 路径和可读内容；前后文件大小、mtime、SHA256 一致，无 resume 或发送操作。
