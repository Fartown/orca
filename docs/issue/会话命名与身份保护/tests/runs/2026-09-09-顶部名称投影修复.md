# 顶部名称投影修复

范围：[TC-264/265](../cases/顶部名称投影测试.md)、REQ-025。分支 feat/claude-owner-window，HEAD 9899e7148023 加未提交修复；不声称合入或用户安装完成。

## 原因与证据

只读 Provider `session_index.jsonl` 的 thread_name 和 SQLite threads.name，与 Orca 持久 aiVaultTitle、Issues provider_title 一致。两条截图会话分别为 Continue Orca session / Read prior Orca session，Orca generatedTitle 分别为 Continue work from the prior Orca / 继续；并非漏读另一个更好的原生名。SQLite title 是迁移首 prompt，不等于原生短名，未归档正文。

`useTabGroupItemProjections` 先解析出 Provider 名，但构建输出 TerminalTab 漏传 aiVaultTitle；`tab-bar-item-surface` 再调用 resolveTerminalTabTitle 时，只剩 generated 和 title，generated 抢在已经解析的 title 前。Sidebar 读取原始 terminal slot，所以两边不一致。

修复保留 Provider slot 到最终渲染，backing terminal 存在值或 null 时优先；仅 undefined 才兼容 unified。无新 RPC、DB、排序或 Provider 写入。
