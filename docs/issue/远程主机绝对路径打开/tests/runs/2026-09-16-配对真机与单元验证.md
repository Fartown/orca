## 3. TC-801 真机执行记录

夹具文件放在主机临时目录，**不属于任何 worktree**，因此 worktree 相对的 `files.*` 完全无法寻址它——只有 grant 能到达。

| 观测项 | 结果 |
| --- | --- |
| 弹窗给出的行 | `Open file · outside-note.txt` |
| 「只能打开工作区内的文件」 | 未出现 |
| 编辑器 | 正常打开，无 `File not found` |
| Monaco 查找唯一标记 | `1 of 1` |
| 标签页持有的 grant | `{grantId, absolutePath: /private/var/.../outside-note.txt}` |

### 反向对照

移除主机的 `files.grantHostPath` 方法并重新构建，同一条用例失败（编辑器始终不出现）。截图 `evidence/00-before-fix-host-rpc-absent.png`。随后还原并复验通过。

### 真机抓到、单测抓不到的两处

1. **路径未规范化**：主机铸造 grant 时存的是用户输入的 `/var/...`，而其自身的新鲜度检查要求存的是真实路径，macOS 上真实路径是 `/private/var/...` → 主机以 `terminal_file_grant_stale` 拒绝自己刚发的 grant。
2. **编辑器的既有拒绝**：内容加载器有一条「远程工作区不支持外部本地文件」，它的前提正是本功能消除的限制，带 grant 的标签页需要豁免。

两处都不可能被自造替身的单测发现——替身不会复现主机的软链语义，也不会经过编辑器加载器。
