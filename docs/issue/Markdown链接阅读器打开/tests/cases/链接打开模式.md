# 链接打开模式

| 功能             | 关联需求 | 是否测试 | 预期                       | Test Case |
| ---------------- | -------- | -------- | -------------------------- | --------- |
| 带行号保持阅读器 | REQ-1541 | 是       | 新开和已开的 md 不切源码   | TC-1541   |
| 源码标签跳行     | REQ-1542 | 是       | 已在源码时跳到指定行       | TC-1542   |
| 明确跳行入口     | REQ-1543 | 是       | 快速打开 `:行号` 仍切源码  | TC-1543   |
| 手机端预览       | REQ-1544 | 是       | 先阅读模式，切源码后定位行 | TC-1544   |

### TC-1541 带行号的链接保持阅读模式

关联 REQ-1541。P1，单测和真实 UI。前置：工作区里有 `docs/guide.md`，至少 30 行，默认模式没改过。分别在本地工作区和 SSH 工作区各做一遍。步骤：在终端输出 `docs/guide.md:20`，点击这个链接。预期：md 标签以阅读模式打开，没有切到源码。

### TC-1542 源码标签跳行

关联 REQ-1542。P1，单测和真实 UI。前置：`docs/guide.md` 已经打开，并已手动切到源码。分别在本地工作区和 SSH 工作区各做一遍。步骤：再次点击 `docs/guide.md:20`。预期：标签保持源码模式，光标落在第 20 行。单测还要覆盖两种情况：默认模式为源码时跳行；默认模式为源码，但标签手动切回了阅读模式时不跳行。

### TC-1543 明确跳行入口不变

关联 REQ-1543。P2，真实 UI。步骤：在快速打开里输入 `guide.md:20` 并确认。预期：切到源码，光标落在第 20 行。

### TC-1544 手机端预览

关联 REQ-1544。P1，手机真机。前置：手机连着桌面 Orca，分别测本机工作区和 SSH 工作区。步骤：在会话终端里点击 `docs/guide.md:20`。预期：预览先显示阅读模式；切到源码后，滚动定位到第 20 行。
