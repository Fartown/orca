# 锚点与评论访问

| 功能           | 关联需求 | 是否测试 | 预期                   | Test Case |
| -------------- | -------- | -------- | ---------------------- | --------- |
| 引文重定位     | REQ-7901 | 是       | 旧行号失效时仍定位原文 | TC-7901   |
| 失效评论       | REQ-7902 | 是       | 卡片可见且可编辑删除   | TC-7902   |
| 主机归属与兼容 | REQ-7903 | 是       | 内容和原主机持久化保持 | TC-7903   |

### TC-7901 引文移动

关联 REQ-7901。P1，单测和真实 UI。前置：本地/SSH 的 Markdown 评论引文存在，保存行号落在分隔行或超出范围。步骤：展开评论栏。预期：卡片按现有引文匹配定位，不误标为失效；正常旧行号不回归。

### TC-7902 引文移除

关联 REQ-7902。P1，单测和真实 UI。前置：本地/SSH 文件已有多个评论，删除其中的引文。步骤：展开评论栏、编辑失效评论、重开文档并删除该评论。预期：每条评论都有可访问卡片；失效卡片显示原文已变更；编辑、删除生效且无关评论保持。包含空文档、分隔行、越界行号、尺寸测量失败与行偏移。

### TC-7903 主机与内容保留

关联 REQ-7903。P1，真实 UI 和契约检查。前置：本地或通过认证 SSH 转发连接的隔离执行主机拥有文件和评论。步骤：读回主机评论、渲染和编辑/删除卡片，再次从原主机读回。预期：仅目标评论变更，文件字节保持；既有 RPC 和 schema 不变；SSH 身份验证、文件读写和评论持久化均在执行主机发生，客户端不增加重连。
