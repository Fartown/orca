## 测试期间问题与归因

各次失败日志保留在 `evidence/name-e2e*`，最终通过运行没有覆盖之前证据。

- 早期断言假定项目头 anchor 总为本机目录，实际原手动排序可以选远端；改为核对实际 header 及原目录成员。
- 原设置页首次打开会把未知 upstream 探测为 null；夹具明确初始化为已知无 upstream，与目标 dbox 当前状态一致。未改变产品的 icon/upstream 探测逻辑。
- `[data-worktree-id]` 同时命中侧栏与其他工作区界面，断言增加原侧栏区块键定位。
- 新增 Git 夹具首次调用进程封装用了不存在的 command 参数；按实际 `ProcessSpec.program` 修正。随后 Local/SSH Git 与普通目录场景共同通过。
- E2E 通用 setup 尝试补齐 `/usr/local/bin/orca-dev` 链接时权限不足，但为非致命日志，未更改用户链接，不影响测试执行。
