# 总管执行主机与启动等待

### TC-355 选择来源、开启与重开

- 关联需求：REQ-033；P0；真实界面、持久化。
- 在总管执行主机列表选择 Local Mac、配对主机和真实 managed SSH 主机，分别打开与重开，再在来源间切换。
- 预期：实际源 HOME/工作目录/原 pane 与选择一致；旧本机浮动会话兼容；远端 folder 在来源 profile，重开原会话不多起进程；显示远端目标时最小化原本机总管浮层以露出内容，不影响其他浮动会话。每个来源的会话和偏好独立保留。

### TC-356 prehook 等待内容可见

- 关联需求：REQ-033；P0；真实终端与 Chat。
- 在无 providerSession 的 Claude 总管呈现真实格式目录信任菜单；同时验证已有 providerSession 的 ready 会话。
- 预期：waiting 可见同一 pane 的实际终端菜单，不留 Chat 空白；ready 默认 Chat 可读原 provider 会话；不代用户确认信任，不重开替代会话。

### TC-357 提案、收件箱与唤醒归属

- 关联需求：REQ-030、REQ-031、REQ-033；P0；端到端及故障注入。
- 远端总管提案后在桌面确认；来源自己的任务、其他库任务分别产生动态；执行中切换来源和注入迟到回复。
- 预期：提案结果、conversation、watch、inbox 与输入全部回原来源；外库任务 ID 不被当成本库同名 ID；只唤醒所选来源，旧异步结果不覆盖新列表或输入。

### TC-358 失联、恢复与旧版

- 关联需求：REQ-018、REQ-033；P0；真实网络与请求计数。
- 中断来源 TCP，等共享层判失联；观察 dispatcher 请求与共享连接事件；恢复共享联系；选择不支持 capability 的来源。
- 预期：显示无法确认，禁读禁输入，不回退本机、不私有重试或重连；恢复仍原 pane/PID；旧版明确拒绝，原来源会话保留。

### TC-359 创建边界与普通 folder

- 关联需求：REQ-033；P0；后端、权限、平台。
- 并发 prepare、只读库、profile 关闭、目录记录被改来源、登记事务故障、重复 receipt 与手机调用。
- 预期：只在来源 profile 建专用目录，复用同一 group/folder；拒绝错来源及权限调用；失败回滚 session preference；不以 git worktree 为前提，不改用户 SSH 配置。
