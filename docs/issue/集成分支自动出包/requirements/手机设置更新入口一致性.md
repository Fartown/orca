# REQ-416 Android 集成包更新入口一致

关联 Fartown/orca#131；优先级 P1；状态：已实现。

集成 Android 包的外层设置页必须复用关于页的 mobileUpdates 更新器和状态。检查不能调用 source=null 的旧上游 checker；下载中返回设置页必须显示同一进度，检查/下载/校验期间点击不能启动第二次请求。校验、安装权限、继续安装、真实错误都保持既有控制器语义；打开系统安装器不等于安装成功。versionName 相同仍按 native versionCode 判断更新。

官方 Android、iOS 和非集成渠道保留原更新来源。更新运行在手机，清单/下载来自既有 fork Release URL；无 paired/SSH 主机读写或重连，无新增服务、文件或端口；手机未配对、连接本地或 SSH 主机时行为相同。
