# 预览大小边界

### TC-401 完整文档字节边界

- 关联需求：REQ-401。
- 模块/优先级/类型：文档读取，P0，真实文件集成。
- 前置与数据：隔离临时目录中的 HTML 文件，含中文内容和独立结束标记。
- 操作：经本地 runtime、SSH relay 真实编解码链和配对预览 RPC 路由分别读取 512 KiB+1、20 MiB、20 MiB+1 文件；中文与 emoji 跨分块边界。
- 预期：前两者完整返回、结束标记保留；超限文件拒绝，不返回截断正文。SSH 内存管道传输测试与配对 RPC 编解码测试不冒充真实远端部署或 Electron UI 验收。
- UI 验收区分入口：SSH／配对的 `orca-preview://` 验证上述边界；纯本地 `file://` 验证 20 MiB 正常显示并保持原行为，不要求新增超限拒绝。宿主内部方法测试不是纯本地 UI 入口的证明。

### TC-402 普通读取和远端预算不扩大

- 关联需求：REQ-402。
- 模块/优先级/类型：文件读取与传输，P0，回归。
- 前置与数据：普通文本文件、paired 请求预算、二进制预览输入。
- 操作：执行原有普通文件及 paired 预算测试；用超 512 KiB 文档发起带远端预算的读取。
- 预期：普通读取和未协商分块的旧客户端保留原上限；JSON 编码后超预算仍拒绝；二进制上限、授权与主机选择不变。

### TC-403 分块兼容与完整性

- 关联需求：REQ-401/402。
- 模块/优先级/类型：分块读取，P0，兼容回归。
- 操作：旧主机返回不含 chunk 的完整响应；新主机返回空文件、二进制文件、缺失字节、文件版本变化。
- 预期：旧主机正常回退；空文件与二进制保持原语义；缺失字节或版本变化拒绝，不拼接错误正文；每次响应保持既有传输预算内。
