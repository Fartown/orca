# 已确认事实

- mobile/app/settings.tsx 挂 SettingsAppUpdateSection；它调用 appUpdateChecker.checkNow。
- app-update-runtime.ts 的 resolveAppUpdateSource 对 integration 返回 null；app-update-checker.ts 的 checkNow 在 source 为空时直接 resolve failed，没有网络请求。
- AboutScreen 挂 IntegrationUpdateRow；它和顶部 IntegrationUpdateGate 均读 mobileUpdates.store，使用 fork 清单、native versionCode 和既有 APK 校验/安装接口。
- 用户截图的顶部下载 29% 与设置检查失败对应两套彼此独立的状态源。

未知：截图未提供 APK 的 versionCode/构建 SHA；本机未发现已运行 adb 通道或可直接使用的无窗原生模拟器。本轮不操作用户手机。
