# 跨主机会话关联回归

预期来源为用户跨主机关联要求、REQ-032、D-026，及项目既有执行主机所有权、失联不重连和本机/SSH一致性约束。

### TC-351 双向关联并保持原会话

- 关联需求：REQ-012、REQ-016、REQ-018、REQ-032；优先级 P0；类型：真实界面与持久化。
- 前置条件：两个隔离 Orca 已配对且在联系，双方各有任务和已有会话，其中任务可已有自己的默认工作区。
- 步骤：分别在 A 的已有会话选择 B 的任务、在 B 的会话选择 A 的任务；再从任务中打开所关联会话。
- 预期：候选显示任务库名称；关联保存在任务原库，包含原执行主机持久身份及原始 tab/pane；任务默认工作区不变；打开的是原会话，未新增替代会话；本机 git 与 folder 工作区均适用。

### TC-352 持久身份与同名会话隔离

- 关联需求：REQ-032；优先级 P0；类型：迁移、身份与客户端投影。
- 前置条件：任务库为 v7 的有效库，存在会话和已读标记；两个执行主机可具有同名 raw pane/session。
- 步骤：升级后关联外部会话；重开库；令 runtime incarnation 或客户端 environmentId 变化；再令源身份晚于任务关联到达、或出现冲突身份。
- 预期：旧会话与已读标记保留；同名 pane 按持久执行身份隔离；不二次镜像；身份晚到能重新投影；冲突或身份缺失时不能回退本机，也不能把任务库所在主机当执行主机。

### TC-353 SSH 与联系中断

- 关联需求：REQ-018、REQ-032；优先级 P0；类型：真实 SSH 和状态行为。
- 前置条件：独立 SSH 执行主机及已联系的任务库，任务库与执行主机可不同；记录实际 tab/pane 与主机路径。
- 步骤：关联并打开 SSH 已有会话；分别失去任务库、源 Orca、嵌套 SSH 联系，再恢复共享连接状态。
- 预期：SSH 的源 endpoint 和其相对 target 均保留；断联期间没有对该主机的读写、私有重试或自动重连；只显示无法确认；恢复跟随共享事件，原关联和原会话不换。

### TC-354 兼容、手机与失败保护

- 关联需求：REQ-012、REQ-016、REQ-017、REQ-032；优先级 P0；类型：界面、协议与故障。
- 前置条件：旧版任务库、手机有/无源主机可信缓存、已有会话关联，以及可注入写入拒绝的隔离夹具。
- 步骤：在旧库选择跨主机候选；手机打开外部会话并尝试任务内回复；同库换关联时令新建失败；跨库换关联时令新建失败、旧关联移除拒绝、旧移除已提交但响应丢失；在来源目录迟到、同名本机会话和不同嵌套 SSH 位置时回复；复验普通同工作区关联和新开会话。
- 预期：旧库明确提示升级且不发跨库写；手机仅在唯一可信已连接源路由可用时打开源主机完整会话，其他情况下禁开禁回复，不借任务库 client 发给错误会话；同库原子替换失败保留旧关联；跨库新建失败不动旧关联，旧移除结果不明保留新关联并提示核对，不因回滚造成两边皆空；来源目录与保存身份不一致时不进入发送器，不查询本机终端；原生约束和行为保持。
