# 终端聊天视图恢复

用户要求修好 Fartown 安装包中无法发现或使用 Chat View 的问题，并完成合入与安装验证。

### REQ-1801 已有终端可双向切换视图

优先级：P0。当前状态：实现中。

支持原生聊天视图的终端标签，右键菜单提供「切到聊天视图 / Switch to Chat View」（与终端头部、窗格右键同名，见 [终端头部切到聊天视图 REQ-2](../../终端头部切到聊天视图/requirements/requirement.md)；上游的 Continue in Chat UI 在中文里已改指「在新聊天中接管」）；聊天视图提供 Continue with Terminal Agent。两者调用已有同标签切换入口，保留终端 ID、进程和 provider session。普通 shell、不支持的 agent、缺少切换回调的标签不显示此项。切换不创建标签、不启动或恢复 provider 会话、不发送用户消息。

### REQ-1802 本地和 SSH 行为一致

优先级：P0。当前状态：实现中。

本地文件夹和 Git 工作树、SSH 执行主机均沿用已有能力判断、会话路由和 transcript 读取。执行主机拥有 transcript 与终端进程，客户端仅切换展示；不增加 RPC、端口、设置、文件副本或重试。旧主机维持其已有能力判断。快捷键标签复用跨平台绑定，移动端的原生聊天入口保持已有行为。

### REQ-1803 历史会话可读且只读校验

优先级：P0。当前状态：实现中。

对用户指定旧标签核对 Orca 的 provider session 元数据；如缺失，只用已核实的会话标识及已有绑定入口修复元数据。读取并显示已有 transcript，前后校验文件未改动；不 resume 旧 provider、不发送消息、不关闭原终端。此项是既有配置的修复验收，优先复用现有接口。
