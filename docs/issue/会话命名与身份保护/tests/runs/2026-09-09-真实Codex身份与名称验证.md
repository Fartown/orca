## 4. 归因与修复边界

真实原生子Hook带`agent_id`；`src/shared/agent-hook-listener.ts`对这类Codex事件不提取覆盖父身份的providerSession。独立B没有`agent_id`，却继承A的pane和launch token，因而按普通新会话被接受；A后续Hook再把身份切回。B的SessionStart距前一A的PreToolUse约2,504ms，这次并非父会话长时间静默造成的未知边界。

Claude活跃窗口仅在`source === 'claude'`时生效，本轮验证暴露的是Codex未分类独立调用缺口，不能用Claude PASS或Codex原生子Agent PASS代替。当前产品仍未满足“所有内部调用都不影响父身份/名称”的全量目标。本轮不擅自把Claude 30秒规则推广给Codex，也不新增身份/角色系统；缺陷保留为P1未解决，后续修复应以本次真实失败用例作回归，并同时验证正常同pane换会话不会被误拦。
