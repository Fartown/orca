# 切换与绑定

- TC-1801（REQ-1801）：支持的终端右键显示聊天入口，点击仅调用同标签切换一次；聊天视图可返回终端，原 handle 和 PID 保持。
- TC-1802（REQ-1801）：普通 shell、无能力或缺少回调时不显示切换；原有历史会话操作菜单仍在正确分组。
- TC-1803（REQ-1802）：本地和真实 SSH 执行端分别运行隔离 App；已有 transcript 在两种展示间切换，终端进程保留。不新增或替换 provider 会话。
- TC-1804（REQ-1803）：核对用户旧标签的 provider session ID、执行主机 transcript 路径和可读内容；前后文件大小、mtime、SHA256 一致，无 resume 或发送操作。

- TC-1805（REQ-1804）：当前前台的终端聊天实例收到现有恢复请求，保持聊天模式并恢复原绑定；本地、SSH 及 paired runtime 身份分别覆盖，主机拒绝输入不查询客户端本地 PTY 注册表。
- TC-1806（REQ-1804）：输入框失去实时绑定后，旧版在聊天模式拒绝恢复、终端模式允许；修复版在聊天模式允许。真实后台实例比较相同故障注入前后结果，读取 DOM 的 placeholder/contenteditable，不以 store 值单独验收。
- TC-1807（REQ-1804）：视图隐藏、终端覆盖层撤销、实例卸载、错误 tab 或没有具体实例时不得借聊天模式恢复；等待 liveness 期间视图变化同样拒绝。
- TC-1808（REQ-1802、REQ-1804）：本地及真实 SSH 链路运行修复版，原 handle、PTY 和 incarnation 保持；不发送用户消息、不终止原进程；SSH 端服务与客户端端口分别记录所属主机。
