## 边界

日常 `/Applications/Orca.app` 未替换，用户活动配置未修改，因此不能报告用户当前侧栏已经完成归并。当前本地包使用开发签名，没有发布到自动更新渠道。完整新建 SSH 管理服务的部署流程、异机网络和原生手机 UI 没有在本轮实机运行；已覆盖 SSH 主机限定成员的分组逻辑，以及真实 paired host 的点击与执行归属。

额外执行的全仓 `pnpm typecheck:e2e` 报告既有 cloud 包、mobile stub 与多处 E2E fixture 类型错误；没有为通过该命令改动无关代码。两项本功能 E2E 均实际执行通过。
