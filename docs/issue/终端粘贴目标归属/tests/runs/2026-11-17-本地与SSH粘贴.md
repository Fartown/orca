## 测试边界与失败修正

- 剪贴板 IPC 是可控 Promise，返回测试标记；没有读取或改写用户系统剪贴板。PTY、宿主 stdin、SSH 连接与 App 都是真实的。按键在隐藏 renderer 中派发，不是原生系统焦点或权限弹窗验收。
- 首次 SSH 夹具在接收程序就绪前执行，不能证明真实接收；已加入由接收程序输出的 `PASTE_OBSERVER_READY`，最终结果只取就绪后的完整重跑。
- 一次测试专用 SSH 隧道本机监听仍在但请求超时，宿主直连健康响应 404 用时 0.009908 秒；只重建该专用隧道后本机响应 404 用时 0.003981 秒，再完整重跑通过。未把夹具故障归为产品根因。
- 多分屏对照中，旧版也能正确路由；不是已确认根因。入口改动复用既有焦点 pane 解析，消除对隐含同步顺序的依赖。
- 用户截图当次没有细分焦点/绑定日志，本轮证明的是明确的误取消边界与残留提示，不能宣称还原了当次事件时间线。
