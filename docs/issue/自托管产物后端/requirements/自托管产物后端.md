# 自托管产物后端

## 1. 背景、目标与来源

原先客户端只接受第一方域名与 loopback，自托管服务受限于 Orca 所在机器。提交 `d3cffbd3e817a5ebc95c8034f900ec355f477b6f` 将地址范围扩到私有 IPv4 与 `.local`，支持局域网部署。这是本需求的原始来源；规则已对照当前 `artifact-cloud-config.ts` 与测试，未另行定义服务端能力。

本需求独立管理产物 API 配置与验收，不依赖 Issues 看板或 Goal 调度。

目标分级：P0 为配置优先级、合法 origin 和局域网地址支持；P1 为鉴权复用与实际执行主机的请求链验证；未另设 P2 交付承诺。优先级不等于实现或验收状态。

## 2. 场景与范围

用户在发起产物 API 调用的 Orca 主机上配置局域网服务地址，继续使用既有产物分享、发布、列表和删除链路。Git worktree 与 Folder Workspace 使用相同配置逻辑。

In scope：origin 解析、配置优先级、HTTP/HTTPS 与主机限制、沿用现有身份和请求链。2026-09-10 本轮修复范围增加：现有独立后端改为单个 HTTP 端口，对本机及 LAN 提供 API 和分享页面；客户端默认访问本机后端。Out of scope：自动服务发现、新增用户配置流程、网络代理、证书分发、任意公网第三方服务，以及改变账号授权规则。

## 3. 需求点

### REQ-201 产物 API 配置优先级

- 目标级别：P0；当前状态：已实现，源码及包内运行时已验证，当前 App 尚未安装。
- 来源：原始提交；2026-09-10 用户明确要求直接在逻辑里写死本地默认地址，不增加启动脚本或持久配置流程。
- 规则：非空显式 `apiUrl` 优先，其次 `ORCA_ARTIFACTS_API_URL`，最后默认 `http://127.0.0.1:8787`；空白先 trim。
- 验收：解析结果为标准化 `URL.origin`。正常启动的 macOS App 即使未继承环境变量，Artifact 操作也使用本地 HTTP；本地连接失败直接报错，不切换到线上。该默认值只作用于 Artifact 业务入口，共用解析器的其他调用方保持原行为。

### REQ-202 支持 loopback 与局域网 origin

- 目标级别：P0；当前状态：已实现。
- 规则：`127.0.0.1`、`localhost`、`[::1]`、`10/8`、`192.168/16`、`172.16/12` 以及以 `.local` 结尾的主机名允许 HTTP 或 HTTPS。
- 验收：私有 IPv4 按四段数值判定；形似私有地址的公网域名不被接受，`172.15.*` 与 `172.32.*` 不在放行范围。
- 边界：这是客户端主机名分类，不执行 DNS/IP 路由验证，也不证明服务实际可达；IPv6 ULA、`.lan` 或任意内部域名不在此扩展范围。

### REQ-203 保持 origin 和公网地址约束

- 目标级别：P0；当前状态：已实现。
- 规则：公网仅接受 `onorca.dev` 及其子域的 HTTPS；拒绝其他协议、userinfo、非根路径、query、fragment。
- 验收：`10.0.0.1.evil.com` 一类地址被拒绝；公共第一方 HTTP 被拒绝；合法 URL 返回规范化 origin。

### REQ-204 复用产物身份与请求链

- 目标级别：P1；当前状态：已实现，真实远端部署未验收。
- 规则：放宽 origin 不放宽显式 auth token override；override 仍仅允许非 production 且非 packaged 环境。常规调用继续使用 active profile 的 Orca 账号会话。
- 验收：请求发送到所选 origin 的 `/v1/artifacts` 路由；鉴权、幂等与分享记录沿用既有实现，重定向仍拒绝，超时仍为 20 秒。
- 主机边界：环境变量属于实际执行 `ArtifactCloudService` 的进程；客户端机器可访问某地址不能证明 SSH/paired runtime 侧也能访问。

### REQ-205 单个 HTTP 入口服务本机与局域网

- 目标级别：P0；当前状态：已实现，本机经 LAN IP 验证通过，第二台设备未验收。
- 来源：2026-09-10 用户要求 HTTP、LAN 可访问，并纠正双端口和启动脚本的处理方式。
- 规则：本地后端使用单个 HTTP 端口提供 Artifact API 与分享页面；用户通过已有 Orca 功能使用服务，不需要运行专用启动脚本或配置 CA。
- 验收：本机默认 origin 为 `http://127.0.0.1:8787`；LAN 可通过 `http://<服务器 LAN IP>:8787` 访问，返回的分享链接使用该 LAN origin。保留已有产物内容与 slug。
- 边界：本需求围绕 Artifact 后端；Orca 账号等其他线上服务沿用原有行为。
