# 主机路由测试用例

| 用例 | 需求 | 断言 |
| --- | --- | --- |
| 本地 | REQ-901、REQ-903 | 当前聚焦其他主机时仍使用本机 RPC，客户端写入 ID |
| 直接 SSH | REQ-901、REQ-903 | 已连接 SSH 经本机 runtime 查询；失联不查询 |
| 配对主机 | REQ-901、REQ-903 | 精确选择所属环境，git/folder/SSH 代理均支持 |
| 失败隔离 | REQ-902 | 归属不明、失联、RPC 错误不回退本机，不写剪贴板 |
| 剪贴板错误 | REQ-902、REQ-903 | 写入异常透传原菜单失败提示 |
