## 执行与文件归属

客户端 Electron、隔离 HOME/profile、CDP、日志和截图在本机。客户端所有窗口始终隐藏，使用 ORCA_BACKGROUND_LAUNCH=1，没有激活、切换或退出用户的 Orca。

本地 server/daemon/folder workspace 在 `/tmp/orca-shell-mode-156.a71swj7j`。Mini 的 server、daemon、独立 profile 和 folder workspace 在 `/tmp/orca-shell-mode-156.UKOoKu`。两端服务仅绑定各自主机的 127.0.0.1；客户端 SSH 转发口指向 Mini 的服务端口。配对凭据只存在忽略的临时私有文件中。

这覆盖客户端在本机、执行和文件在 SSH 主机的现行 SSH 隧道 + paired runtime 路径；没有将其称为旧 relay 的单独真机验证。旧 relay PTY 到 runtime handle 的身份转换有定向单测。移动端沿用相同 wire，但本轮没有原生手机/平板验收。
