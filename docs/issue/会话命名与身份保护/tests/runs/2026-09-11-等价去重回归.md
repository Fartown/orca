## 实际变更

1. parser 直接复用上游 `isCodexWorkerSession`，删除自有 metadata 模块的相同副本；title reader 的精确 `field` 和来源优先级不变。
2. 删除重复的 `.docs` 打包排除规则，保留既有相同规则。该配置已与集成 `831bde8f7` 字节一致，消除本需求在该配置中的新增差异。
3. 登记已有上游 helper 依赖和新增回归测试。命名源码变更激活了此前新建的 worktree scope，暴露旧需求迁移的 18 项漏登记；仅补具体旧文档路径及原迁移使用的两项基础设施路径，不增加 Issues 产品权限，不修改迁移文档正文。

两个产品源码文件加打包配置为 +3/-16，净减 13 行；这不包含测试、登记和文档。原有 69 个上游产品接缝没有减少，不能把一处配置差异消失算成少一个产品接缝。

parser 状态原位搬回未实施：简单搬回的静态非空非注释行数约 311，已超过 300 行规则，格式化展开 import 还会增加行数；不提高门禁，也不为此扩大改写。
