# 本地任务管理切片 1 真机验证（2026-10-26）

- 对应：[功能测试](../cases/本地任务管理功能测试.md) 第 1 节 TC-001～TC-016。
- 构建：`feat/local-tasks` 工作区的 e2e 构建（`pnpm run build:packages && pnpm exec electron-vite build --mode e2e`），SSH 用已有的 `out/orcad-template`。
- 方式：Playwright 驱动后台启动的隔离实例（`ORCA_BACKGROUND_LAUNCH=1`，独立 userData），CDP 截图，界面以中文为主、英文抽查 3 屏。SSH 用 root 运行的 `127.0.0.1:2222` sshd；手机路径用 `pairMobileClient` 走真实 WebSocket；配对服务器用无头 `orca serve` 夹具。没有启动任何智能体。
- 证据（本机目录，不进仓库）：`.docs/local-tasks-ui-validation/2026-10-26/slice1/`，`README.md` 是逐条结果，`evidence/` 是截图和 JSON，`scripts/local-tasks-slice1-driver.spec.ts` 是驱动脚本。
