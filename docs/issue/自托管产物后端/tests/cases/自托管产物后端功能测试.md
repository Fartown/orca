# 局域网 Artifact 分享功能测试

可重复执行的测试规格；实际结果记入 `../runs/`。需求来源为 [自托管产物后端](../../requirements/自托管产物后端.md)，方案见 [局域网 Artifact 分享服务重构方案](../../solutions/局域网Artifact分享服务重构方案.md) 6.3 节。

每个功能都按两种场景验收：文件在你操作的电脑上；文件在另一台电脑上（经 SSH 打开的工作区）。

## 1. 功能清单

| 功能                     | 关联需求 | 自动化用例     | 真机用例                     |
| ------------------------ | -------- | -------------- | ---------------------------- |
| 由文件所在电脑提供链接   | REQ-301  | AT-03、AT-05   | TC-01、TC-02、TC-11、TC-21   |
| 服务跟着 App             | REQ-302  | AT-02          | TC-08、TC-13、TC-17、TC-18   |
| 不复制文件、不经其他程序 | REQ-303  | AT-01、AT-06   | TC-03、TC-04、TC-05          |
| 端口与链接 IP            | REQ-301、REQ-304 | AT-02、AT-14 | TC-12、TC-19           |
| 访问范围与请求安全       | REQ-305  | AT-01、AT-04、AT-12 | TC-06、TC-07、TC-14、TC-16 |
| 分享弹层                 | REQ-306  | AT-07、AT-08   | TC-01、TC-09、TC-10、TC-11   |
| Artifacts 页             | REQ-307  | AT-13          | TC-07、TC-08                 |
| 命令行与 Agent 指南      | REQ-308  | AT-10、AT-11   | TC-15                        |
| 停用旧入口               | REQ-309  | AT-09          | TC-11、TC-20                 |

## 2. 自动化用例

执行命令登记在 `config/fork-features.jsonc` 的 `self-hosted-artifacts.checks`。

### AT-01 分享记录与链接拼装

- 关联需求：REQ-303、REQ-305。
- 文件：`src/main/self-hosted-artifacts/store/artifact-share-records.test.ts`。
- 覆盖：一个工作区一个随机码、并发写入不丢记录、停止分享作废随机码且重新分享得到新随机码、新版本 Orca 写的记录拒绝读取且不覆盖、端口设置默认值与保存。

### AT-02 静态文件服务跟着 App

- 关联需求：REQ-302、REQ-304。
- 文件：`src/main/self-hosted-artifacts/server/artifact-share-app-server.test.ts`。
- 覆盖：首选端口监听、身份记录与停止后状态为 `stopped`；首次被占用时换端口并记住；记住后被占用报端口冲突、重启后恢复；关闭开关记为 `sharing-off`；第二个 Orca 使用正在运行的服务，提供者退出后接手。

### AT-03 文件所在电脑上的分享操作

- 关联需求：REQ-301、REQ-303、REQ-305。
- 文件：`src/main/self-hosted-artifacts/artifact-share-owner-service.test.ts`。
- 覆盖：分享前给出会开放的工作区；同一工作区复用随机码；服务未提供时按状态报 `artifact_sharing_disabled`、`artifact_share_orca_not_running`、`artifact_share_port_conflict`、`artifact_share_serve_failed` 且不写记录；不在工作区里的文件只分享所在目录；复用已分享的上层文件夹；符号链接越界、`.env`、密钥、目录、已删除文件报 `artifact_share_path_denied`；停止后重新分享得到新随机码。

### AT-04 请求解析与 HTTP 响应

- 关联需求：REQ-305。
- 文件：`src/main/self-hosted-artifacts/server/artifact-share-request-path.test.ts`、`artifact-share-http-handler.test.ts`。
- 覆盖：路径段检查（`..`、编码后的 `..` 与反斜杠、空段、`//`、未知前缀）、非法编码返回 400、真实路径包含判断与越界符号链接、目录只返回 `index.html`、敏感路径与错误随机码 404、POST 返回 405、`nosniff` 头、Markdown 渲染页的 CSP 且内容无法跳出数据元素、`?raw=1` 返回原文。

### AT-05 按文件所在电脑分发

- 关联需求：REQ-301。
- 文件：`src/main/self-hosted-artifacts/artifact-share-routing.test.ts`、`artifact-share-rpc-error.test.ts`。
- 覆盖：本机直接处理；另一台电脑经连接转发并还原错误码；连不上、对方过旧、通道断开都不回退本机；配对的远程 Orca 按其本机处理；配对调用方不能再嵌套另一台电脑；`artifactShare.*` 方法经 RPC 保留分享错误码。

### AT-06 另一台电脑上的处理

- 关联需求：REQ-301、REQ-303。
- 文件：`src/main/self-hosted-artifacts/artifact-share-relay-service.test.ts`、`artifact-share-relay-bundle.test.ts`。
- 覆盖：远程组件注册全部方法；那台电脑的 Orca 没开时可查询、不可分享并保留错误码；畸形参数返回结果信封而不是让连接出错；远程组件的引用链不带 Electron、不含 Node 18 不支持的调用。

### AT-07 分享弹层状态机

- 关联需求：REQ-306。
- 文件：`src/renderer/src/components/self-hosted-artifacts/share-button/lan-artifact-share-machine.test.ts`。
- 覆盖：已分享显示链接、未分享写明工作区；各服务状态对应的阻断原因；带错误码的失败转为阻断、其他失败可重试；分享失败保留原视图并显示错误；重新检查时保留电脑名。

### AT-08 判断文件所在电脑与工作区

- 关联需求：REQ-306。
- 文件：`src/renderer/src/components/self-hosted-artifacts/share-button/lan-artifact-share-target.test.ts`。
- 覆盖：从绝对路径和相对路径得出工作区根目录（POSIX、Windows、盘符根目录）；SSH 工作区文件交给那台电脑；工作区外打开的 SSH 文件不传根目录；配对远程 Orca 的文件交给它，其下的 SSH 主机拒绝；无法确定电脑时拒绝。

### AT-09 上游接缝回归

- 关联需求：REQ-306、REQ-309。
- 文件：`src/renderer/src/components/editor/EditorPanelHeader.test.tsx`、`src/renderer/src/components/browser-pane/workspace-doc/HtmlDocPreview.toolbar.test.tsx`、`HtmlDocPreview.failure-message.test.tsx`、`src/renderer/src/hooks/useSettingsNavigationMetadata.test.ts`、`src/renderer/src/components/settings/OrcaAccountSettingsPane.test.tsx`、`src/renderer/src/components/orca-profiles/OrcaProfileSignOutConfirmDialog.test.tsx`、`src/renderer/src/components/unexpected-signout/`。
- 覆盖：账号设置页、退出登录确认框与意外登出提示卡不再把 Artifact 分享说成需要登录；编辑器头部只在非 diff 的 Markdown 上显示分享入口；工作区文档预览工具栏带分享按钮后行为不变，且按钮不依赖确认弹窗等上下文就能渲染；设置页 Artifacts 分区描述。

### AT-10 命令行参数与转发

- 关联需求：REQ-308。
- 文件：`src/cli/self-hosted-artifacts/artifact-share-cli-target.test.ts`、`src/relay/remote-artifact-cli-input.test.ts`、`src/cli/index.test.ts`。
- 覆盖：本机终端按终端所在工作区（含文件夹工作区）确定范围，工作区外的文件不传根目录；SSH 终端只转发主机上的路径、不读文件内容、不受 CLI 传输上限限制，且不使用本机的 `ORCA_WORKSPACE_ROOT`；`service status` 针对终端所在电脑；从链接或随机码取随机码；`artifacts list` 走本机桌面 runtime。

### AT-11 Agent 指南

- 关联需求：REQ-308。
- 文件：`config/scripts/orca-cli-skill-guidance.test.mjs`；门禁 `pnpm run verify:bundled-skill-guides`。
- 覆盖：指南说明开关默认关闭且只能由人打开、设置项名称、拒绝时的错误码与不要重试、`list`、`unshare`、`delete` 不受开关限制；打包进 CLI 的指南与源文件一致。

### AT-12 真实服务与浏览器冒烟

- 关联需求：REQ-305。
- 脚本：`.docs/artifact-lan-share-ui-validation/2026-09-17/scripts/share-server-browser-smoke.mjs`（本地，不入库）。
- 覆盖：在临时目录起真实服务，用无头 Chromium 打开 Markdown 链接（亮、暗两种主题），检查标题、表格、代码高亮、KaTeX、Mermaid、相对图片、相对链接跳转、`file:` 链接不可点、内嵌脚本不执行、无控制台错误；静态 HTML 的相对 CSS 生效；敏感路径、目录、错误随机码、编码越界、原始 `..` 请求、POST 的状态码；停止分享后链接 404；服务停止后状态文件为 `stopped`。

### AT-13 Artifacts 页的电脑分组

- 关联需求：REQ-307。
- 文件：`src/main/self-hosted-artifacts/artifact-share-rpc-methods.test.ts`。
- 覆盖：列表包含本机、已连接的 SSH 主机（显示用户起的名字）、分享过但没连着的主机（状态为无法确认）；配对调用方只看到本机；对方过旧时标为 `host-outdated` 而不是空列表。

### AT-14 链接 IP 的选择

- 关联需求：REQ-301。
- 文件：`src/main/self-hosted-artifacts/server/artifact-share-lan-ip.test.ts`。
- 覆盖：VPN 隧道网卡抢到默认路由探测时不选它（按 minizc 2026-09-17 的真实网卡组合）；多张物理网卡时优先探测到的默认路由；Tailscale 排在局域网之后，虚拟网桥与公网地址最后；识别 macOS、Linux、Windows 的 VPN 网卡名；固定的 IP 离开这台电脑后回退到自动选择。

## 3. 真机用例

测试电脑：minizc（有桌面 Orca）、mbp5（有桌面 Orca，8787 被 llm-proxy 占用）。不替换正在使用的 Orca 时，可用独立构建在一台电脑上起两个实例经本机 sshd 互连执行（脚本见 `.docs/artifact-lan-share-ui-validation/2026-09-17/scripts/run-lan-share-two-instance.sh`），另一台电脑只用来访问链接。

| 编号  | 关联需求          | 场景                   | 操作                                                                                                           | 期望                                                                                   |
| ----- | ----------------- | ---------------------- | -------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| TC-01 | REQ-301、REQ-306  | 分享本机文件           | minizc 开启分享；在 minizc 的 Orca 里分享调研文档；在 mbp5 的浏览器打开链接                                    | 链接形如 `http://minizc的局域网IP:端口/随机码/tmp/tasks/…`；4 个 Mermaid 图和表格正常显示 |
| TC-02 | REQ-301           | 分享另一台电脑上的文件 | 在 mbp5 的 Orca 里打开 minizc 上的同一文档并分享                                                               | 得到和 TC-01 相同的链接；mbp5 上没有分享记录、没有新占用的端口                         |
| TC-03 | REQ-303           | 不复制、读最新内容     | 修改文档并保存后刷新链接；再修改但不保存                                                                       | 保存后立刻显示新内容；未保存时不显示，弹层提示保存后可见；分享记录目录里没有文件内容   |
| TC-04 | REQ-303           | 相对路径               | 文档里放同目录图片、`../` 上级目录图片、指向同工作区其他 `.md` 的链接                                          | 图片都能显示；点链接打开另一个文档的渲染页                                             |
| TC-05 | REQ-303           | 同一工作区复用随机码   | 分享同一工作区里的第二个文件                                                                                   | 不再弹「整个工作区」提示；链接用同一个随机码                                           |
| TC-06 | REQ-305           | 敏感路径与越界         | 把链接路径改成 `.git/config`、`.env`、`../` 越界、指向工作区外的符号链接、目录（无 index.html）                | 全部 404；服务不出错                                                                   |
| TC-07 | REQ-305、REQ-307  | 停止分享               | 在 Artifacts 页停止分享该工作区，再打开之前的所有链接；然后重新分享                                            | 旧链接全部 404；重新分享得到新随机码                                                   |
| TC-08 | REQ-302、REQ-307  | 跟着 App               | 分享后退出 mbp5 的 Orca、断开与 minizc 的连接；再退出 minizc 的 Orca；再打开 minizc 的 Orca                    | 第一步后链接可打开；退出 minizc 的 Orca 后打不开；重新打开后恢复，链接不变             |
| TC-09 | REQ-306           | 对方 Orca 没开         | 退出 minizc 的 Orca（保持 mbp5 连着 minizc），在 mbp5 上分享 minizc 的文件                                     | 提示 minizc 上的 Orca 没有打开；分享记录没有新写入                                     |
| TC-10 | REQ-306           | 对方没开启分享         | minizc 关闭分享开关，在 mbp5 上分享 minizc 的文件                                                              | 提示请在 minizc 的 Orca 里开启；没有写入                                               |
| TC-11 | REQ-301、REQ-309  | 连不上时不乱发         | 断开 mbp5 与 minizc 的连接后，在 mbp5 上对 minizc 的文件点分享                                                 | 提示连不上 minizc；mbp5 的 llm-proxy 日志没有新请求                                    |
| TC-12 | REQ-304           | 端口                   | mbp5 开启分享；人为占用已确定的端口后重启 mbp5 的 Orca；再在设置里更换端口                                     | 第一次自动确定端口；被占用后显示端口冲突；更换后新链接可打开、旧链接失效               |
| TC-13 | REQ-302           | 关闭开关               | minizc 关闭分享开关后打开已有链接；再打开开关                                                                  | 关闭后打不开、端口释放；打开后原链接恢复                                               |
| TC-14 | REQ-305           | HTML 站点              | 分享一个带相对 CSS、JS、图片和 `fetch` 本地 JSON 的 HTML 页面（本机和经 minizc 工作区预览入口各一次）          | 页面完整显示、脚本和数据正常加载                                                       |
| TC-15 | REQ-308           | 命令行                 | minizc 本地终端和 mbp5 里打开的 minizc 终端各执行 `orca artifacts share`（文件大于 800 KiB）；再执行 `unshare` | 都输出 minizc 提供的链接；大文件成功；`unshare` 后链接失效                             |
| TC-16 | REQ-305           | 恶意请求               | 对分享端口发 `//`、`//..%252f…`、超长地址、POST、非法编码、随机猜测的随机码                                    | 返回 400 / 404 / 405；服务不出错；日志有记录                                           |
| TC-17 | REQ-302           | 升级与重启             | 升级 minizc 的 Orca；另测重启 minizc 后打开 Orca                                                               | 两种情况下原链接都恢复，端口和随机码不变                                               |
| TC-18 | REQ-302           | 同时开两个 Orca        | minizc 同时打开正式版和开发版 Orca                                                                             | 只有一个在监听；两个里分享都得到可用链接；关掉提供者后另一个接手                       |
| TC-19 | REQ-301、REQ-304  | 链接 IP                | minizc 有两个网卡和一个 VPN 地址；查看默认链接后，在 minizc 设置里改选另一个 IP     | 默认使用物理网卡上的局域网 IP，不选 VPN 地址；改选后下拉框显示所选 IP，界面上的新链接可打开 |
| TC-20 | REQ-309           | 云端分享已停用         | 调用 `artifacts.publish`                                                                                       | 返回 `Artifact service is unavailable.`，没有任何对外网络请求                          |
| TC-21 | REQ-301           | 配对的远程 Orca        | 通过配对连接打开远程电脑上的文件并分享（优先级较低）                                                           | 由那台远程电脑的 Orca 提供链接                                                         |
