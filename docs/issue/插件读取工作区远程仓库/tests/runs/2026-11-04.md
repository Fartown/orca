## 真机（隐藏窗口的隔离实例 + 开发插件）

开发插件为 trusted-worker，`probe` 返回 `readContext` 与 `workspace.list`，并记录收到的 `workspace.changed`。SSH 主机为本机 root 运行的 sshd `127.0.0.1:2222`，工作区由 SSH 主机上的 orcad 托管。

| ------------------- | ---- | ------------------------------------------------------------------------------------------ |
| 本地 · HTTPS 带令牌 | 通过 | 三处都给 `https://code.example.test/team/app.git`                                          |
| 本地 · SCP 写法     | 通过 | 原样给出                                                                                   |
| 本地 · 没有远程     | 通过 | 不出现 `remote`                                                                            |
