## 4. 缺陷与遗留问题

- 独立诊断发现：本机 `presentation: background` 原会话在侧栏可见，但点击未 materialize 原 tab，另开普通终端；未触达本次关联请求。保留 `probe-run-2026-11-16T12-49-10-168Z/source-activation-failure.json`。本轮验收本机采用已有视觉 tab，仍为隐藏实例；配对和 SSH 原后台来源实际恢复并通过。
- 1440×900 宽预览下约 300px 的右侧任务列内，既有会话行文本与动作挤叠；原终端已显示，关联行为通过。未将此现象混入路由修复。
- Windows/Linux 原生窗口、原生手机界面及真实模型输入未实测。
- 总管目录信任菜单导致 Chat 空白，以及总管执行位置固定本机，另在主工作区 `.docs/dispatcher-empty-chat-ui-validation/2026-11-16/README.md` 记录；本轮不替用户选择信任，也未改总管启动主机。
