## 2. 决策点记录

以下决策点均**待用户确认**，「推荐」是方案的默认假设；确认或改选后在此更新并同步需求与方案。

### D-001 总管本体：智能体 CLI 会话，还是 Orca 内置的模型循环

- 日期：2026-11-04
- 背景：Muse、Dots、Cue 是厂商托管的智能体，自带模型调用、凭据与沙箱；DeepSeek Super-agent 和 agent-autoloop 则把现成的命令行智能体当作路由与执行者。Orca 目前不直接调用任何大模型 API，凭据都是各 CLI 自己的登录；结构化会话、手机聊天、编排唤醒都已围绕 CLI 会话建好。
- 最终决定：待用户确认。推荐第一项。
- 原因：复用 Claude Code / Codex 的能力、登录与用量；手机现在就能和它聊天；编排的协调者、唤醒、问答直接可用；Orca 不新增模型凭据与计费面。代价是总管的行为受所选 CLI 的上下文与压缩影响，用账本与记忆兜底。
- 影响范围：REQ-2301、REQ-2303；方案 §0、§3。

#### 备选项

- 总管是用户选定的智能体 CLI 的结构化会话，作为编排协调者（推荐）
- Orca 内置模型调用循环与工具调用，自管 API Key

#### 关联文档与需求点

- 无

### D-002 总管所在机：桌面，还是常开的服务器

- 日期：2026-11-04
- 背景：总管需要看到所有主机。桌面 Orca 持有 SSH 连接与配对服务器，看得最全；但桌面合盖、关机时总管就不在线。常开的 `orca serve` 主机能 24 小时在线，但要由它持有对其他主机的连接。
- 最终决定：待用户确认。推荐第一项，并把「搬到常开主机」放进切片 5。
- 原因：第一期最少改动、最符合现有连接归属；离线时如实显示「总管不在线」，在主机上按时干活的事交给自动化（不依赖桌面开着）。
- 影响范围：REQ-2301、REQ-2306、REQ-2312；方案 §7、§10。

#### 备选项

- 第一期固定在桌面 Orca，之后支持迁到常开主机（推荐）
- 第一期就要求一台常开的 `orca serve` 主机

#### 关联文档与需求点

- 无

### D-003 默认主动性档位

- 日期：2026-11-04
- 背景：参考产品都把「默认安静、可调」当作关键；DeepSeek 要求没人请求的工作先只记录。
- 最终决定：待用户确认。推荐「跟进」。
- 原因：用户最在意的是「派出去的事有人盯、要我时叫我」；「建议」「按规则执行」等用户看过它的判断再放开。
- 影响范围：REQ-2311、REQ-2305。

#### 备选项

- 跟进：只盯自己派的和用户让它盯的（推荐）
- 建议：在跟进之上主动发现问题并给建议卡片
- 只听吩咐

#### 关联文档与需求点

- 无

### D-004 动作默认级别

- 日期：2026-11-04
- 背景：需求 REQ-2307 给出了一张默认级别表。争议最大的两项：给用户自己开的会话发消息、以及推送与合并 PR。
- 最终决定：待用户确认。推荐按表执行：驱动用户的会话、停止与删除、不可逆与对外一律先问；改规则只能在设置里。
- 原因：这些动作出错代价高或不可撤回；先窄后宽，用户可在设置里逐项放开。
- 影响范围：REQ-2307；方案 §4.3、§5.3。

#### 备选项

- 按需求表的默认级别（推荐）
- 更激进：总管自己建的工作区可自动删除，推送自动允许

#### 关联文档与需求点

- 无

### D-005 第一期的通知渠道

- 日期：2026-11-04
- 背景：agent-autoloop 把飞书卡片做成主通道；Orca 已有桌面通知、手机推送与手机聊天，另有 Slack 连接器样板。
- 最终决定：待用户确认。推荐第一期只用桌面与手机，外部渠道放切片 5。
- 原因：桌面与手机零新增凭据和对外发送面；外部渠道涉及机器人身份与对外消息，按 REQ-2307 属于「对外」，单独做更稳。
- 影响范围：REQ-2305、REQ-2313。

#### 备选项

- 桌面 + 手机（推荐）
- 第一期同时接飞书

#### 关联文档与需求点

- 无

### D-006 总管默认用哪个智能体、界面叫什么

- 日期：2026-11-04
- 背景：结构化会话支持 Claude（Agent SDK）与 Codex（app-server）等；界面名称影响侧栏与手机首页文案。
- 最终决定：待用户确认。推荐默认 Claude Code、可切 Codex；界面名称暂用「总管」。
- 原因：Claude 结构化会话读取工作区的 `CLAUDE.md`、设置与技能，规则与权限配置最直接。
- 影响范围：REQ-2301；方案 §3、§6。

#### 备选项

- Claude Code 默认，可切 Codex；名称「总管」（推荐）
- Codex 默认；名称「Super Agent」
