# 远程工作区绝对路径打开功能测试

这是可重复执行的测试规格；实际结果另记入 `../runs/`。需求来源为 [远程工作区绝对路径打开](../../requirements/远程工作区绝对路径打开.md)，方案为 [标签栏新建Tab弹窗远程工作区打开绝对路径方案](../../solutions/标签栏新建Tab弹窗远程工作区打开绝对路径方案.md)。

## 1. 功能清单

| 功能 ID | 关联需求 | 功能点 | 是否测试 | 预期表现 | Test Case |
| --- | --- | --- | --- | --- | --- |
| F-01 | REQ-301 | 本地工作区绝对路径行为不变 | 是 | 本地授权、平台校验、打开与改动前一致 | TC-501、TC-511 |
| F-02 | REQ-302 | SSH 工作区绝对路径在远端打开 | 是 | 出现「打开文件」行；stat 带 connectionId；不调用本地授权 | TC-502、TC-504、TC-510、TC-512 |
| F-03 | REQ-303 | 路径平台按工作区主机判定 | 是 | 远程按 POSIX 校验，本地按客户端平台 | TC-502、TC-503 |
| F-04 | REQ-304 | worktree 外 SSH 文件带归属标记 | 是 | worktree 外写 externalSshTargetId，worktree 内不写 | TC-504、TC-505 |
| F-05 | REQ-305 | 归属未就绪与主机漂移时拒绝 | 是 | 状态行不可点；提交中主机变化即中止 | TC-506、TC-509 |
| F-06 | REQ-306 | 远程 runtime 只放行 worktree 内路径 | 是 | worktree 内经 files.stat 打开；worktree 外只给状态行 | TC-507、TC-508 |

## 2. 用例

单元用例的实现位置：`src/renderer/src/components/tab-entry-remote-path/absolute-path-host-policy.test.ts`（策略）、`src/renderer/src/components/tab-bar/tab-create-entry-action.test.ts`（执行链）、`src/renderer/src/components/tab-bar/tab-create-entry-classifier.test.ts`（分类器）。

### TC-501 本地 worktree 策略为 local 且按客户端平台校验

- 关联需求：REQ-301；优先级：P0；类型：单元；模块：主机策略。
- 前置条件：store 内有一个 `hostId: 'local'` 的已知 worktree；客户端平台 mock 为 win32。
- 数据：worktreeId `repo-local::/Users/me/repo`。
- 步骤：调用 `resolveTabEntryAbsolutePathHostPolicy`。
- 预期：返回 `{ kind: 'local', pathPlatform: 'windows' }`。

### TC-502 已连接的 SSH worktree 策略为 ssh 且平台为 posix

- 关联需求：REQ-302、REQ-303；优先级：P0；类型：单元；模块：主机策略。
- 前置条件：repo 带 `connectionId: 'ssh-1'`；`sshConnectionStates` 含 `ssh-1` 且 `connectionGeneration` 已发布；客户端平台 mock 为 win32。
- 步骤：调用 `resolveTabEntryAbsolutePathHostPolicy`。
- 预期：返回 `{ kind: 'ssh', connectionId: 'ssh-1', pathPlatform: 'posix' }`；客户端平台不影响结果。

### TC-503 策略映射到分类器上下文

- 关联需求：REQ-303、REQ-306；优先级：P0；类型：单元；模块：主机策略。
- 步骤：对 blocked、ssh、runtime 三种策略调用 `toTabEntryAbsolutePathContext`。
- 预期：blocked → `allowAbsolutePaths: false` 且平台为客户端平台；ssh → 允许且 `posix`，无 scope；runtime → 允许、`posix`、`absolutePathScope.worktreePath` 为 worktree 路径。

### TC-504 SSH 绝对路径在远端打开且不调用本地授权

- 关联需求：REQ-302、REQ-304；优先级：P0；类型：单元；模块：执行链。
- 前置条件：`runtimeContext` 带 `connectionId: 'ssh-1'`，worktreePath `/home/me/repo`。
- 数据：classification `absolute-file` `/home/me/notes.md`。
- 步骤：调用 `openTabEntryWithOperations`。
- 预期：`authorizeExternalPath` 未被调用；`statRuntimePath` 以该 context 和路径被调用；`openFile` 收到 `relativePath === filePath` 且 `externalSshTargetId: 'ssh-1'`，目标 group 为传入 group。

### TC-505 SSH worktree 内路径保持相对且不打标记

- 关联需求：REQ-304；优先级：P0；类型：单元；模块：执行链。
- 前置条件：同 TC-504。
- 数据：`/home/me/repo/src/index.ts`。
- 步骤：调用 `openTabEntryWithOperations`。
- 预期：`openFile` 收到 `relativePath: 'src/index.ts'`，参数对象没有 `externalSshTargetId`；`authorizeExternalPath` 未被调用。

### TC-506 归属未就绪时保持封禁

- 关联需求：REQ-305；优先级：P0；类型：单元；模块：主机策略。
- 前置条件：分别构造：未知 worktree；SSH repo 但 `sshConnectionStates` 为空；本地与 paired runtime 归属冲突；folder workspace 无 project group；folder workspace 混合本地与 SSH repo。
- 步骤：调用 `resolveTabEntryAbsolutePathHostPolicy`。
- 预期：全部返回 `kind: 'blocked'`；分类器对 `allowAbsolutePaths: false` 的绝对路径只给状态行「Absolute paths are unavailable until the workspace host is ready.」。

### TC-507 paired runtime 的 worktree 内绝对路径按相对路径打开

- 关联需求：REQ-306；优先级：P1；类型：单元；模块：执行链。
- 前置条件：`runtimeContext.settings.activeRuntimeEnvironmentId = 'hub-a'`，worktreePath `/repo`，`absolutePathScope.worktreePath = '/repo'`。
- 数据：query `/repo/src/index.ts`。
- 步骤：调用 `openTabEntryWithOperations`。
- 预期：`statRuntimePath` 被调用；`openFile` 收到 `relativePath: 'src/index.ts'` 且无 `externalSshTargetId`；`authorizeExternalPath` 未被调用。

### TC-508 paired runtime 的 worktree 外绝对路径在分类阶段拦下

- 关联需求：REQ-306；优先级：P1；类型：单元；模块：分类器与执行链。
- 前置条件：同 TC-507。
- 数据：query `/tmp/notes.md`。
- 步骤：分别调用 `classifyTabEntryQuery` 与 `openTabEntryWithOperations`。
- 预期：分类结果为 `blocked`，文案「This remote workspace can only open files inside its worktree.」；执行链以该文案拒绝，`statRuntimePath`、`authorizeExternalPath`、`openFile` 均未被调用。

### TC-509 提交过程中主机漂移即中止

- 关联需求：REQ-305；优先级：P0；类型：单元；模块：主机策略与执行链。
- 前置条件：`isSameTabEntryAbsolutePathHost` 比较 ssh 与 ssh（不同 connectionId）、ssh 与 local、runtime 与 runtime（不同 environmentId）、任一方 blocked。
- 步骤：调用比较函数；执行链用会在授权后开始抛错的 `assertAbsolutePathAllowed` 打桩。
- 预期：以上组合均返回 false；执行链在授权后抛出并未调用 `statRuntimePath` 与 `openFile`。

### TC-510 SSH folder workspace 得到 ssh 策略

- 关联需求：REQ-302、REQ-305；优先级：P0；类型：单元；模块：主机策略。
- 前置条件：folder workspace 带 `connectionId: 'ssh-1'`，`sshConnectionStates` 已发布 generation。
- 步骤：调用 `resolveTabEntryAbsolutePathHostPolicy`。
- 预期：返回 `{ kind: 'ssh', connectionId: 'ssh-1', pathPlatform: 'posix' }`；本地 folder workspace 返回 local。

### TC-511 本地绝对路径仍先授权再打开

- 关联需求：REQ-301；优先级：P0；类型：单元；模块：执行链。
- 前置条件：`runtimeContext` 无 `connectionId`、`settings` 为 null。
- 数据：`/tmp/notes.md`；Windows 客户端场景 `C:\tmp\notes.md`。
- 步骤：调用 `openTabEntryWithOperations`。
- 预期：`authorizeExternalPath` 以规范化路径被调用；POSIX 客户端拒绝 Windows 路径并报「Enter an absolute path for this computer.」；Windows 客户端规范化盘符路径后 stat。

### TC-512 selector 记忆化与重算

- 关联需求：REQ-302；优先级：P1；类型：单元；模块：主机策略。
- 前置条件：已连接的 SSH worktree。
- 步骤：`skip: true` 时读取 selector；无关切片写入 1000 次；`sshConnectionStates` 置空后再读。
- 预期：skip 时返回稳定的 blocked 引用且不解析归属；无关写入不重复解析，返回同一引用；切片变化后重算为 blocked unresolved。

## 3. 真机验证用例

真机验证按 `AGENTS.md` Electron UI Validation 执行（`ORCA_BACKGROUND_LAUNCH=1`、CDP 截图、不抢焦点），证据放 `.docs/remote-workspace-absolute-path-open-ui-validation/日期/`。TC-513～TC-515 需要一台已连接的 Linux SSH 主机。

### TC-513 SSH 工作区打开 worktree 外的远端绝对路径

- 关联需求：REQ-302、REQ-304；优先级：P0；类型：端到端；模块：弹窗与执行链。
- 前置条件：一个已连接的 Linux SSH 工作区；远端在 worktree 之外存在一个文件。
- 步骤：点击标签栏「+」，输入该远端绝对路径，回车。
- 预期：出现「打开文件」行且详情为完整路径；新建编辑器 tab，标题为完整路径；该 tab 的 `externalSshTargetId` 等于工作区的 connectionId。

### TC-514 SSH 工作区打开 worktree 内的远端绝对路径

- 关联需求：REQ-302；优先级：P0；类型：端到端；模块：弹窗与执行链。
- 前置条件：同 TC-513；远端 worktree 内存在一个文件。
- 步骤：输入该路径并回车。
- 预期：出现「打开文件」行；新建 tab 标题为 worktree 相对路径；不写 `externalSshTargetId`；弹窗内不出现主机未就绪或工作区外的状态行。

### TC-515 SSH 工作区打开不存在的远端路径

- 关联需求：REQ-302；优先级：P1；类型：端到端；模块：执行链。
- 前置条件：同 TC-513。
- 步骤：输入一个远端不存在的绝对路径并回车。
- 预期：弹窗内显示 `File not found: …` 错误行，弹窗保持打开，未新建 tab。

### TC-516 本地工作区绝对路径回归

- 关联需求：REQ-301；优先级：P0；类型：端到端；模块：弹窗与执行链。
- 前置条件：一个本地 git 工作区；worktree 外另有一个本机文件。
- 步骤：分别输入 worktree 内与 worktree 外的本机绝对路径并回车。
- 预期：两次都出现「打开文件」行并新建 tab；worktree 内的标题为相对路径，worktree 外的标题为完整路径；两者都不带 `externalSshTargetId`。
