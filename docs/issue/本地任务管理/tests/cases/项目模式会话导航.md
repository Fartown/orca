# 项目模式会话导航

预期来源：用户2026-11-17截图与明确要求、D-028、Issue139。关联REQ-026、REQ-028；以下为规格，实际结果写入Run。

### TC-360 两种模式与即时切换

- 优先级：P0；已关联任务不应劫持项目模式的会话入口。
- 前置：隔离桌面，已有可见会话及已关联任务，记录原工作区/tab/pane/PTY。
- 默认无模式偏好、显式关闭、任务源隐藏时，真实点击项目侧栏会话，均激活原会话，不打开任务页或任务会话面板。
- 启用任务模式，真实点击任务树的会话，所属任务与宽会话面板正常打开；明确打开任务入口保留。
- 任务→项目→任务切换后立即点击，按当前模式动作，不等旧行回调重新渲染；无任务关联写入，会话身份不变。
- 保持宽或窄任务会话面板打开，直接切回项目模式并点击会话；不先关闭面板或绕经其他页面，旧面板消失且原会话可见。

### TC-361 本机、文件夹与SSH来源

- 优先级：P0；相同入口规则必须保持实际执行主机与原进程。
- 参数：本机Git工作区、普通folder、真实SSH来源；任务关联到本库或另一库时均按当前客户端模式打开。
- 项目模式点击精确侧栏会话，回到原工作区/tab/pane；任务模式保持所属任务与会话联动。
- 不同host/pane、歧义关联仍交原路径处理，不误开其他任务。
- 共享层判SSH来源不在联系后，项目入口不跳任务，不新增功能私有读取、重连或重试；恢复跟随既有共享流程。
- 清理仅本轮自有key/HOME/profile/进程；原会话handle/PTY/incarnation/PID不因导航变化，不改用户任务库或原生App。
