# 局域网 Artifact 分享功能测试

可重复执行的测试规格；实际结果记入 `../runs/`。需求来源为 [自托管产物后端](../../requirements/自托管产物后端.md)，方案见 [局域网 Artifact 分享服务重构方案](../../solutions/局域网Artifact分享服务重构方案.md) 6.3 节。

每个功能都按两种场景验收：文件在你操作的电脑上；文件在另一台电脑上（经 SSH 打开的工作区）。

### AT-20 分享页功能走查（对照 Orca 内置预览）

  - 外观与适配：暗色主题；中文浏览器显示中文文案且 `<html lang>` 为 `zh`；手机宽度目录收起、无横向滚动、评论卡排在块下方、点一下块出现「添加评论」且在屏幕内；全程无页面错误。
  - 大文档（1.1 MB）：0.6 秒内显示「正在准备预览」，约 9 秒后出正文与目录。
