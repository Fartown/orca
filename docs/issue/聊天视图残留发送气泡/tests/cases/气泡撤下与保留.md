# 气泡撤下与保留

- TC-8001（REQ-8001）：单元测试。发送边界与对应行都不在一页已完成、仍有更早历史的新消息里时，气泡被撤下；读取进行中不撤，读取完成后撤。
- TC-8002（REQ-8001、REQ-8002）：本地真机。隔离实例的 Claude 终端以聊天视图显示，从聊天框发送一条消息，切到另一个标签，向 transcript 追加对应行和超过 300 条后续消息，切回后底部不再有该气泡，最新消息在最后。
- TC-8003（REQ-8001、REQ-8002）：SSH 真机。工作区与 transcript 在 127.0.0.1:2222 的 SSH 主机上，重复 TC-8002，结果相同；不新增读取路径。
- TC-8004（REQ-8003）：单元测试。写入失败、送达未确认、等待写入确认的气泡保留；窗口仍覆盖到边界时间、边界行仍在窗口、已加载全部历史、无边界行或无主机时间时保留；hook 预览不影响窗口时间判断。
- TC-8005（REQ-8004）：手机单元测试。会话页重连后拿到一页无重叠、仍有更早历史的新消息，文字和图片气泡都撤下；已加载全部历史时保留。
