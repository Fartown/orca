# 「以任务为主」交互原型

这是[产品方案](../任务为主的工作流产品方案.md)的可交互原型，桌面和手机各一份。用浏览器直接打开 `index.html`（`file://` 就可以），不需要构建，也不联网。

- `index.html`：入口页，列出每一屏的截图和说明，点截图进入那一屏。
- `desktop.html`：桌面原型（1440×900 的 Orca 窗口）。地址里的 `#d1`、`#d13` 等是屏幕编号。
- `mobile.html`：手机原型（390×844 的 iPhone 画框）。真实手机 App 的文案是英文；原型为了方便评审，用的是简体中文。
- `screenshots/`：每一屏的截图，文件名就是屏幕编号。
- `assets/`：字体。

样式和脚本都内联在页面里，所以仓库的 lint 和格式检查只会看到 HTML。原型是评审材料，不是产品代码：不进构建、不跑测试，也不被任何代码引用。

## 和技术方案的差异

原型按产品方案画，有两处还等[技术方案](../../solutions/任务为主的工作流技术方案.md) §2.3 定：

- **Q1**：原型里，任务模式下的任务视图有「概览 + 会话」标签栏（d13-task、d13-task-waiting、d13-shop12）。技术方案建议不做这排标签，会话都开在浮层里，「全屏」切到工作区原有的标签。
- **Q2**：原型里，手机抽屉里的终端会话可以直接打字（m5）。技术方案建议只有聊天会话在抽屉里回答，终端会话点开直接进会话页。
