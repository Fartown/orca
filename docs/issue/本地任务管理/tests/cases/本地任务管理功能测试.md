# 本地任务管理功能测试

- 需求：[本地任务管理](../../requirements/本地任务管理.md)
- 方案：[本地任务管理技术方案](../../solutions/本地任务管理技术方案.md)
- 场景说明：
  - **本机**：客户端和工作区都在本机。
  - **SSH**：客户端是桌面 Orca，工作区在 SSH 主机上。本机验证用 root 运行的 `127.0.0.1:2222` sshd，步骤见 `docs/reference/ssh-real-app-validation.md`。
