# 工作区恢复与目录收敛测试用例

| 功能 ID | 关联需求 | 功能点       | 是否测试 | 预期表现                 | Test Case |
| ------- | -------- | ------------ | -------- | ------------------------ | --------- |
| F-1     | REQ-2001 | 历史选择     | 是       | 不生成无内容工作区       | TC-2001   |
| F-2     | REQ-2002 | 主机目录收敛 | 是       | 只处理取得目录的主机     | TC-2002   |
| F-3     | REQ-2003 | 内容保留     | 是       | 名称、编辑和会话归属保留 | TC-2003   |

## TC-2001 仅有历史选择

- 关联需求：REQ-2001；模块：恢复；优先级：P0；类型：回归。
- 前置条件和数据：本地项目正常；远端分区包含已移除 repo 的 terminal 选择、访问历史和排序，内容为空。
- 操作：启动恢复，刷新目录，再保存并恢复一次。
- 预期：没有额外工作区或 Unknown；正常本地工作区和真实 SSH 终端保留。

## TC-2002 主机范围与失败

- 关联需求：REQ-2002；模块：目录；优先级：P0；类型：集成。
- 前置条件和数据：两个主机有同 ID 工作区，其中一个只有恢复占位。
- 操作：分别完成一台主机的目录刷新、模拟另一台失联、拒绝过期结果。
- 预期：只对成功且当前主机的恢复占位收敛；其他主机、本机和文件夹工作区保留；失败不执行清理。

## TC-2003 可恢复内容与 SSH 访问

- 关联需求：REQ-2003；模块：恢复、内容；优先级：P0；类型：端到端。
- 前置条件和数据：本地文件夹和真实 SSH 工作区可访问；不再登记的远端项目含编辑器、草稿、浏览器或 agent 标签。
- 操作：恢复并刷新主机项目目录，再重启隔离客户端。
- 预期：编辑标签继续可见，恢复容器显示名称而非 Unknown；主机归属、草稿字节和终端绑定保留；主机不再登记工作区时沿用现有文件不可加载提示，不绕过文件权限；不创建远端 repo、不关闭远端进程。
