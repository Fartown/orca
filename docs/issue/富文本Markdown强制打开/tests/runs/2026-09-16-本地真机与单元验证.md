首版 TC-607 写的是「重开后覆盖仍然生效」。真机跑出来是重开回到默认拦截。查证后确认这是上游既有语义：`src/renderer/src/store/slices/editor/actions/close-file-action.ts:35` 在关闭标签页时删除该 fileId 的覆盖标记，本需求没有改动这条路径，体积覆盖此前也是同样行为。行为本身合理——重开一个文件从安全默认开始，而不是继承一次旧决定。已按实测改写用例预期。
