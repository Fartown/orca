## 实际变更

1. 接收层：`shouldRejectUnbackedCodexStart` 更名为 `shouldRejectUnbackedCodexSessionEvent`，判据由"只在 SessionStart 生效"放宽到该会话的全部事件；仍然只在同一 pane 已有带 transcript 的 Codex 在位会话且会话 ID 不同时启用，且不记忆被拒会话。
2. 候选质量：新增 `codex-recap-task-text.ts`，`isEligibleSessionNamePrompt` 据此拒绝 recap 提示词与它的派生名。这一处是文案匹配，目的是让已经落盘的名字失去候选资格，使下一条真实提示词可以覆盖它。
3. 两处已登记接缝 `src/shared/agent-hook-listener.ts` 与 `src/main/agent-hooks/server/server-ingest-remote.ts` 同步调用点，本地 Hook 与 relay 摄取共用同一判据。

产品源码净变化为 3 个文件小改加 1 个新文件；未新增 DB、wire 字段或设置项，未改动其它命名优先级。
