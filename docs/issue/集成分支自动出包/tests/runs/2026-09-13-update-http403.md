# 更新检查 HTTP403 修复验证

- 关联：REQ-404、REQ-405；TC-404、TC-405。
- 现场：用户手机关于页版本211405816，检查返回HTTP403；当前无手机ADB，不能确定是API、清单还是出口策略，更不能仅凭截图断言限流。
- 已复现缺陷：旧共用源在API403/429时立即失败，即使同仓库公开Atom和完整清单可读也无法继续。
- 修复：仅API403/429回退同仓库Atom；专用integration标签、schema2身份校验和包HEAD确认保留；最多3个候选；清单身份错误、其它HTTP失败不被隐藏成最新版。
