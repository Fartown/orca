## TC-001 同一终端内部变化

关联 REQ-001。模块：快捷键粘贴。P0，集成/真实 App。

前置：隔离 App 中存在接收 stdin 的测试 PTY，焦点在其 helper textarea，读取剪贴板可被测试夹具暂停。

步骤：分别正常粘贴、读取时 blur 到 body、读取时在同 pane 内替换 helper textarea 后 focus；释放读取并查看接收端。

预期：每次内容写入原 PTY 恰好一次；没有向另一个分屏写入；替换节点后不误报焦点变化；原 handle/PTY/incarnation 保留。

## TC-002 真正换目标或失联

关联 REQ-001、REQ-003。模块：归属快照。P0，单元/集成。

前置：已捕获手势时的原目标。

步骤：分别更换焦点到其它 input/另一 pane，替换 transport、PTY、leaf，移除 pane，或使 transport 失去连接，再释放读取。

预期：取消并拒绝发送；不能将旧操作改投新 PTY。能区分焦点变化、目标变化与断联，不把失联当作进程退出，不重连、不重发。

## TC-003 同 pane 粘贴错误恢复

关联 REQ-002。模块：反馈。P1，单元/真实 App。

前置：本 pane 曾有一次粘贴错误，另存同 pane 的无关错误和另一 pane 的错误。

步骤：执行一次成功粘贴。

预期：实际收到一次输入；本 pane 旧粘贴错误消失；无关错误和其它 pane 错误保留。失败回调返回 false，不被上层当作已粘贴。

## TC-004 本地和 SSH 一致性

关联 REQ-003。模块：客户端与执行宿主。P0，真实 App。

前置：隔离 HOME/profile，窗口保持隐藏；本地 git/folder workspace；SSH 连接的宿主上运行独立 profile 的测试 orcad 并创建独立 folder workspace。客户端测试通过 SSH 隧道连接该宿主。

步骤：分别执行 TC-001 与真实切换 input 取消；从实际执行宿主读取接收文件和 terminal.show；核对前后物理身份和窗口状态。

预期：允许的操作在对应宿主接收一次，取消操作没有该内容；不写入其它 pane；原物理身份保留，窗口 hidden/unfocused；混合版本宿主无需新协议。清理仅涉及本轮隔离进程。

## TC-005 迟到请求反馈隔离

关联 REQ-002、D-002。模块：反馈。P1，单元。

前置：同一 pane 连续发起两次粘贴，异步读取和完成顺序可控。

步骤：新请求先失败，旧请求后成功；再验证新请求先成功、旧请求后失败；将同一错误 sink 重新创建监听后重复第一组。

预期：旧成功不能清除新失败，旧失败不能覆盖新成功；切换 tab 重装监听仍保持该约束。之后更新的成功请求可以清理旧粘贴错误。
