这是受控请求故障注入，不是主机成功/失败响应 mock；仅测试实例内 IPC 请求的目标被重写，真实 main/mini 处理器执行拒绝。与用户既有会话不同：验收测的是确定拒绝，历史消息只能标投递未确认。没有运行模型来制造新回合，也不把 pending 气泡当成 provider 已开始处理。

全部 Electron 窗口 visible=false、focused=false，使用隔离 HOME/userData，无 pageerror。local fixture 是临时 Git 工作区与合成 Codex transcript，原文件不触碰。SSH 入口客户端端口 127.0.0.1:46769，目标服务是 mini 的 127.0.0.1:6768；工作区、原 PTY、provider 与原 transcript 属 mini，endpoint 配置只在隔离 profile。SSH 验收为隧道访问配对服务，不涉及原生 SSH relay 自动部署。

SSH 脚本初次选择器碰到预热的隐藏 root，改为可见 root；另一次从尚未绑定的 Chat 开始，最终使用先等待原终端完成 attach、再切 Chat 的顺序验证发送链路。没有为这些准备步骤改产品代码，也不把首次附着问题算作本轮已修复。
