- 代码合入没有让用户运行的旧包自动包含新流程；当前安装交付不满足 REQ-121。
- 2026-09-08 的 GUI 闭环使用固定 CLI 输出，真实 Codex 为分开的生成/裁判探针；不将它们写成一条全真实 GUI 链路。
