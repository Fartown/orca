## SSH 路径与清理

隔离的 paired runtime 拥有测试项目、文件和终端；隐藏客户端经 `127.0.0.1:2222` 的真实 SSH 认证 TCP 转发访问其服务。loopback 端口属于 SSH 客户端；服务端项目目录与文件读取仍由隔离 runtime 处理。现有该端口是用户级 sshd，本轮没有通过它启动后台 relay，也没有启动或替换 sshd。

临时授权只追加专用公钥行，结束时精确移除；原 `authorized_keys` 前后 SHA-256 一致，临时私钥移除，SSH 控制连接和两个隔离实例退出。见 `evidence/ssh-cleanup.json`。用户原 Orca、mini、dbox 和会话未重启或注入测试数据。
