### D-003 固定本地默认地址修复配置丢失

- 日期：2026-09-10
- 背景：macOS 登录恢复的 Orca 未继承环境变量而使用官方默认地址；用户要求直接写死本地默认值，并纠正双端口和启动脚本。
- 最终决定：Artifact 业务入口默认 http://127.0.0.1:8787，保留显式参数和环境覆盖；独立后端单个 HTTP 端口提供 API 和分享页面。
- 原因：按用户明确指令完成最小修复，不增加配置或启动流程。
- 影响范围：REQ-201、REQ-205；共用解析器其他调用方保持原默认值。

- 增加 launchctl 或持久配置读取
