## 真机（隐藏窗口的隔离实例）

| 用例                 | 需求               | 场景                                                                        | 期望                                                              |
| -------------------- | ------------------ | --------------------------------------------------------------------------- | ----------------------------------------------------------------- |
| 本地 · 非 Gitea 平台 | REQ-2101、REQ-2103 | 工作区在本机，远程指向返回 500 的本机服务，app 设置了 `ORCA_GITEA_TOKEN`    | 卡片与 Checks 无 PR；服务只收到不带 Authorization 的 version 请求 |
| 本地 · 真 Gitea      | REQ-2102           | 远程指向假 Gitea 服务                                                       | 卡片显示 PR #9；PR 请求带令牌，version 不带                       |
| SSH · 非 Gitea 平台  | REQ-2101、REQ-2103 | 工作区在 SSH 主机（本机 root sshd 127.0.0.1:2222），远程指向返回 500 的服务 | 同本地；远程地址经 SSH 主机读取，探测由客户端发出                 |
| SSH · 真 Gitea       | REQ-2102           | 工作区在 SSH 主机，远程指向假 Gitea 服务                                    | 卡片显示 PR #9                                                    |

单机验证时 SSH 主机与客户端是同一台机器，无法从服务日志区分请求来自哪台机器；「探测由客户端发出」由代码路径保证：forge 请求在 `forge-provider.ts` 的调用方进程执行，只有 git 读取经 `hostedReviewSshConnectionId` 路由到 SSH。
